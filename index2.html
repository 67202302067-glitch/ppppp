จับคู่หัวข้อคอลัมน์ (Column Header Mapping)

หากชื่อหัวข้อคอลัมน์ใน Google Sheet ไม่ตรงกับระบบ คุณสามารถเลือกแมปคอลัมน์ได้ด้วยตนเองที่นี่:

ขั้นตอนการนำไฟล์ขึ้น GitHub Pages (ฟรี 100%)

ไฟล์นี้ถูกออกแบบให้เป็น **Single-file HTML** ที่บรรจุทั้งส่วนแสดงผล (UI), สไตล์ (Tailwind CSS), ระบบแผนที่ (Leaflet), กราฟ (Chart.js) และตัวดึงข้อมูลเรียลไทม์ไว้ในไฟล์เดียว!
  1. เซฟไฟล์นี้: ตั้งชื่อไฟล์นี้ว่า index.html ลงในคอมพิวเตอร์ของคุณ
  2. สร้าง Repository บน GitHub:
    • เข้าไปที่ GitHub.com แล้วล็อกอิน
    • กดปุ่ม + New Repository
    • ตั้งชื่อ Repo เช่น health-dashboard แล้วกดเลือกเป็น Public
  3. อัปโหลดไฟล์:
    • ในหน้า Repository ใหม่ กดที่คำว่า uploading an existing file
    • ลากไฟล์ index.html ไปวาง แล้วกด Commit changes
  4. เปิดใช้งาน GitHub Pages:
    • ไปที่เมนู Settings ของ Repository นั้น
    • เลือกเมนูย่อย Pages ทางซ้ายมือ
    • ตรงหัวข้อ Build and deployment / Branch ให้เปลี่ยนจาก None เป็น main (หรือ master) แล้วกด Save
  5. เสร็จสิ้น! รอประมาณ 1-2 นาที คุณจะได้ URL เว็บไซต์ เช่น
    https://yourusername.github.io/health-dashboard/
    สำหรับนำไปแชร์ให้ทีมงานและผู้บริหารเข้าดูแบบเรียลไทม์ได้จากทุกอุปกรณ์!
